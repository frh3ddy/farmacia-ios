# Farmacia — Brand Guidelines

## Name and logo

- **Master brand:** "FARMACIA" with the script **F** monogram in a ring. One brand for every location.
- **Locations** are a second line under the wordmark ("SUCURSAL ORIENTE", "SUCURSAL <NOMBRE>"), never part
  of the main name. The original "Farmacia Oriente" logo becomes the Oriente lockup.
- **App icon:** the monogram alone (no text). The dev build adds an amber **DEV** band.

| Asset | File |
|---|---|
| Master lockup | `docs/brand/logo-farmacia.png` |
| Location lockup (Oriente) | `docs/brand/logo-farmacia-oriente.png` |
| App icon (prod / dev) | `FarmaciaApp/Resources/Assets.xcassets/AppIcon*.appiconset` |

All of these are generated by `scripts/brand/render-brand.swift` (`swift scripts/brand/render-brand.swift <outdir>`).
Change colors or add a location there and re-run; don't edit the PNGs by hand.

## Colors

| Role | Hex | Use |
|---|---|---|
| Rosa (primary) | `#FCACAC` | Monogram, wordmark |
| Carbón oscuro | `#3F424A` | Background gradient start, text on amber |
| Carbón claro | `#6E7176` | Background gradient end |
| Ámbar (dev only) | `#F2B33D` | DEV band on the debug icon — never in production art |

Rosa on carbón only; don't put the monogram on white or on photos without the carbón background.

## Type

- Monogram: Snell Roundhand Black (script **F**).
- Wordmark and location line: Avenir Next (Medium / Regular), all caps, wide letter spacing.
- In the app, text follows iOS system fonts and Dynamic Type (see `FarmaciaApp/Core/DesignSystem/` on the design-system branch).

## Logo use

- Keep clear space around the ring of at least the ring's stroke × 4.
- Don't stretch, recolor, rotate, or add effects to the monogram.
- Minimum size: 24 pt monogram on screen; below that the script F loses its hairlines.
